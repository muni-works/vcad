## Coverage

- **Doc/command** (`crates/vcad-app/tests/doc_fuzz.rs`): 20 000 seeded
  sequences of up to 16 hostile steps each (NaN, 1e300, string numbers, nulls,
  empty ids, malformed envelopes, batches). Undo-all/redo-all, save/load and
  eval-validity invariants all hold after the fixes. 600 sequences run in
  well under a second, so the default 120 stays in CI.
- **cargo-fuzz** (12 targets, ASan, seeded from repo files): round 1 ran
  5 min per target and found F4–F6. Round 2 ran 8 min per target on the
  fixed code: see the final note below.
- **Bridge** (`fuzz/bridge_fuzz.py`): 700 requests over 71 tools plus raw
  HTTP garbage (oversized/negative `Content-Length`, binary, chunked junk,
  70 KB paths, 50-message batches). No crash, no wrong-document edit seen.
  Found F2, F3, F10.
- **UI monkey test**: **not run**. It needs full-screen computer-use control
  of the user's Mac. Left as a follow-up.
