## Bugs, ranked

1. **HIGH — document opened straight into Drawing never comes up in 3D.**
   The workspace is restored at launch; Drawing doesn't mount the RealityKit
   viewport, so the first viewport build happens on leaving Drawing, after
   the solve. That late first build is wrong: Drawing→Fab left the
   "Opening… Evaluating" card up forever (all threads idle, title "Solving");
   Drawing→Design drew the model as a huge black silhouette around the camera
   with the gizmo's axes radiating across the screen; Home/orbit didn't
   recover. Repro: View ▸ Drawing, quit, open any `.loon` (or open a second
   file from Finder while in Drawing — the new instance inherits it), View ▸
   Design. Camera state was verified sane (az/el/dist/pan identical to a good
   launch) — it's the scene build, not the camera. Keeping the viewport
   mounted (hidden) under Drawing did **not** help.
   **Fixed (workaround):** launches never restore Drawing/Electronics
   (`Workspace.launchRestorable`), so the viewport always builds first;
   switching into Drawing later is unaffected. Root cause of the bad late
   first build is still open — follow-up below.
2. **MEDIUM — section state lost across workspace switches.** Section on in
   Design → Drawing → Fab: the Section panel is still up but the model is no
   longer cut (the viewport is rebuilt on each switch).
3. **MEDIUM — Frame All didn't fit.** `resetCamera` set a fixed distance 1.5;
   a 60×60×240 mm assembly filled a quarter of the view. **Fixed:** fits the
   model bounds (`frameAllDistance`, viewport aspect kept current).
4. **MEDIUM — hollow section caps on mesh-import parts.** In the K1 PTO
   assembly the `mesh_import` bodies cut to an orange outline with the grid
   showing through; B-rep bodies cap correctly.
5. **LOW — section panel AX press reports failure.** Pressing the ⌥⌘X button
   via accessibility returns `cannotComplete` though the section toggles.
6. **LOW — drawing annotation collisions.** On A4 the FRONT label overlaps the
   title block's top rule; a `25.06` dimension overlaps "ISOMETRIC"; hole
   callouts ("ø18.8", "3× ø3.4") sit on geometry. Mesh-import parts draw
   dense hidden-line hash.
7. **LOW — same file opened twice spawns two instances.** The "already open"
   check only looks at the receiving instance.
8. **LOW — sandbox → document jump on first edit.** Launch shows a warm light
   cube (12,300 tris, flat tree "Cube, Fillet"); the first face click promotes
   it to a document engine: blue-grey material, 11,532 tris, tree "Fillet ›
   Cube". Reads as the model changing under you.
9. **LOW — open selects the root.** Opening a document auto-selects the root
   body with the gizmo up; Fusion opens with nothing selected. Tree labels are
   raw op names ("boolean", "mesh_im…").
10. **LOW — "3D Print: Slice & Export" from Drawing does nothing**; it works
    once in Fab.
