vcad Sketch UX

Design note for Fusion-class sketching in the Mac app: inference while drawing, one Smart Dimension, solve-state colour, editing tools and live profiles.

Inference while drawing

Every drawing tool runs the cursor through SketchInference.infer before it places a point. It returns the snapped point and the constraints that would be added. Candidates, in priority order: coincident with an existing point, midpoint of a line, on a line, horizontal / vertical from the previous point, perpendicular or parallel to the previous segment, tangent from an arc end, equal length to the previous segment, and alignment with any point's x or y (dotted guide). Each candidate shows as a green glyph by the cursor while hovering. On click the glyphs become real solver constraints and stay drawn beside the geometry. Click a glyph in Select to pick it; Delete removes it. Holding ⌘ suppresses inference for one click.

Smart Dimension

One tool (D) decides what to measure from what was clicked: a line gives its length, a circle or arc its radius (diameter for full circles), two points their distance, a point and a line the perpendicular distance, two lines their angle (or distance when parallel). The value is placed at the click and opens an inline field immediately; Return commits and re-solves.

Solve state

Per-entity colour: an entity whose points are all fully determined draws in the foreground colour, the rest in blue, conflicting constraints in red. A pill shows the state and DOF. Dragging a point in Select pins it to the cursor with a temporary fixed constraint, re-solves on every move, and drops the pin on release, so constraints hold as you drag.

Construction and projection

X toggles construction on the selection: dashed grey, still constrainable, never part of a profile. Project (P on a model edge) brings model edges into the sketch as fixed construction references; this is the one item that needs edge picking through the viewport, so it lands after the pure-logic pieces.

Editing tools

ToolKeyBehaviour
TrimTClick a segment piece: removes the part between its nearest intersections.
ExtendEClick near a line end: grows it to the nearest crossing line.
FilletFClick a corner shared by two lines: rounds it with a tangent arc of the set radius.
MirrormenuMirror the selection about a selected line, with symmetric constraints.
PatternmenuLinear or circular copies of the selection.
OffsetmenuExisting profile offset, kept.

Live profiles

Every closed region from loopRegions() is triangulated (ear clipping, holes bridged) and drawn as a translucent fill under the ink as soon as it closes. A filled sketch is ready for Done → Extrude or press-pull.

Tests

  • Inference: H/V, coincident, midpoint, perpendicular, parallel, equal, tangent, and priority between them.
  • Smart Dimension: each pick combination maps to the right constraint kind and value.
  • Profile fill: triangulation area equals the polygon area, with and without a hole.
  • Trim, extend, fillet, mirror geometry helpers.
