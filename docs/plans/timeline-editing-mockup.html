History, simplified

The feature tree is the history. Click any feature, change it in the inspector, and everything after it rebuilds. Undo and redo work as they do today, one named step per edit. If a later feature loses what it was attached to, it gets a red badge and a one-click fix. There is no separate timeline, rollback marker or drag reorder.

bracket.vcad
Try it

Select Extrude1 and change the thickness: everything rebuilds. Select Sketch2 and drag the boss past x = 90: Fillet1 breaks. Then press Undo, or use the fix on the error card.

What makes it safe

Faces get stable names from the feature that made them, so the fillet follows the boss when the sketch changes. When there's no unambiguous match, vcad stops and says so instead of guessing.

Move Up / Move Down

These stay, but a move that would put a feature before its input is refused with the reason. Today that move goes through and the feature silently disappears.

Left out on purpose

Timeline strip, rollback marker, drag reorder, live ghost previews, thumbnails. Add them later only if people ask to insert features mid-history.
