Model: ProgressCenter

An @Observable stack of ProgressTasks. Producers call begin(title:stage:cancel:), update(id, stage:, done:, total:) and end(id); they never own UI.

FieldMeaning
title, stage"Importing STEP", "Building faces"
fraction?0…1, or nil for indeterminate (bar shimmers)
done / totalcounts shown as "339 of 1715"
etaderived from start time and fraction once past 10% and 3 s
cancel?closure; non-nil means cancellable. One ✕, same path for all tasks

Updates are coalesced: the published snapshot changes at most every 100 ms (about 10 Hz). Text uses monospaced digits and no numeric content transition.

Producers moved onto it

  • STEP import and first solve (LoadProgress phases) map onto one task; the card and capsule are removed
  • Re-solves (solveProgress) become a "Solving" task
  • Failures and warnings stay readable: the pill's second line turns red/orange and a click shows details with Retry or OK
  • Later producers (slicing, FEA, exports, agent jobs) call the same three methods
